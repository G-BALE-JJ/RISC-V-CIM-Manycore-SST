> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the full softmax work from `G-BALE-JJ/RISC-V-CIM-Manycore-SST` into the current `wt-huti-v0-full` worktree without breaking the GEMM-only baseline.

**Architecture:** Implement in two phases. First copy and adapt the isolated CPU softmax test flow under `tests/small/mvm_noc_softmax_cpu`, then merge the SFU/RoCC scaffold into `libgolem`. Source files live in the root worktree; `build/sst-elements` is refreshed by the local build script.

**Tech Stack:** SST Elements autotools build, C++17 RISC-V musl test binaries, Bash pipeline wrappers, Python unittest/verification scripts.

- Source repository: `https://github.com/G-BALE-JJ/RISC-V-CIM-Manycore-SST.git`, branch `softmax-update`, observed commit `ef8de7a`.

- Use `/data4/jjgong/RISC-V-CIM-Manycore-SST/install/lib/sst-elements-library` as the default elements library path.
